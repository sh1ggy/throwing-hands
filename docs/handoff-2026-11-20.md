Hardware setup:

- On the HuskyLens, set Protocol Type = Serial, 9600 baud.
- Wiring: adapter TX→R, RX→T, GND→GND.
- Power: one source only (§8.3), either the adapter's 5 V or the camera's micro-USB, never both.
